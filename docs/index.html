Conexión del laboratorio

La URL y las claves de Supabase no se muestran ni se guardan en el repositorio. El docente las carga como secretos de GitHub; al publicar, el sitio las usa sin exponerlas en el código.

En el repositorio: Settings → Secrets and variables → Actions. Secretos: SUPABASE_URL, SUPABASE_ANON_KEY. Opcional: AI_KEY. Variable: AI_PROVIDER (pollinations, groq o gemini).

Después: Settings → Pages → Source → GitHub Actions. Cada push vuelve a publicar el laboratorio.

Todavía no hay aula remota. El trabajo queda en este navegador.
Modelo de IA

Debate sobre el dominio, sin pagar

Pollinations no pide clave. Si el docente cargó Groq o Gemini en los secretos del repo, el aula ya los usa. Si querés, podés poner una clave propia solo en tu navegador.
